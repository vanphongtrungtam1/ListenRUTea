# VSTEP Listening — Urban & Rural Life — Teacher

Phiên bản GitHub Pages được dựng theo đúng template Listening mẫu, thay nội dung sang **Urban & Rural Life**.

## Cấu trúc

- Warm-up: toàn bộ 72 mục Vocabulary/Phrase trong file nguồn Urban & Rural Life; mỗi mục có 4 nghĩa tiếng Việt, đáp án A/B/C/D được phân bổ cân bằng 18/18/18/18.
- Part 1: Questions 1–8 — 8 short announcements or instructions.
- Part 2: Questions 9–20 — 3 conversations, chia thành 6 bộ; Speaker 1 = Male, Speaker 2 = Female.
- Part 3: Questions 21–35 — 3 talks, chia thành 9 bộ.
- B2 Paraphrase Challenge nằm ở cuối từng Part; không có audio/script/evidence.
- Part 2–3: thanh audio sticky theo từng bộ; câu hỏi cuộn tự nhiên. Khi bật Script, khung Script sticky bên dưới thanh audio theo template.
- Bản giáo viên: có Key, Script và Evidence; evidence được highlight đúng cụm thông tin trong script.

## Audio

Gói hiện tại đã được gắn **audio chính thức** cho toàn bộ 23 bộ nghe. Tên file audio đã được chuẩn hóa theo cấu trúc của trang và `exam-data.js`; không đổi tên các file `.wav`.

Tên audio:
- Part 1: `P1.1.wav` … `P1.8.wav`
- Part 2: `P2.1.wav` … `P2.6.wav`
- Part 3: `P3.1.wav` … `P3.9.wav`

## Đưa lên GitHub Pages

1. Giải nén ZIP.
2. Upload **toàn bộ file ngang hàng ở thư mục gốc** của repository.
3. Không đổi tên `index.html`, `style.css`, `app.js`, `exam-data.js`, logo hoặc audio.
4. Vào **Settings → Pages → Deploy from a branch → main → / (root)**.

Trang chính sử dụng `index.html`.
